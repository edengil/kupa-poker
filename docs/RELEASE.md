# צ'קליסט פריסה — kupa-poker

כלל ברזל: לא מדווחים "עלה" לפני שכל הסעיפים עברו, על העץ המדויק שנדחף.

## לפני דחיפה
1. `npm test` — כל בדיקות היחידה ירוקות.
2. אם שונו קבצי קצה או קונפיג: `npm run test:e2e` (פורט 3100, או E2E_PORT אחר).
3. `npm run build` — בילד נקי.
4. הבדיקות רצות על העץ הסופי — אחרי המיזוג/העריכה הידנית האחרונה, לא לפניה.

## אחרי דחיפה ל־main
5. לחכות ש־Vercel יסיים פריסה (סטטוס Ready).
6. להריץ `scripts/verify-live.sh` — בודק שהאתר החי מגיש את הגרסה החדשה:
   - עמוד הקבוצה עונה 200.
   - נתיב התזכורות עונה 403 בלי טוקן (הגנת הרשאות פעילה).
   - הבאנדל החי מכיל מחרוזת סמן של הפיצ'ר האחרון (מעבירים כפרמטר).
7. שינויי `.github/workflows` לא נדחפים בגיט (לטוקן אין workflow scope) — רק דרך ממשק הווב של GitHub.

## שינויי נתונים במסד (Supabase)
8. לפני שינוי בנתוני חלוקה/קופה: מציגים חלוקה מוצעת ומקבלים אישור מפורש מעדן.
9. כל העברה בפועל — שקלים שלמים בלבד; חריגה חייבת להיתפס בוולידטור של מנוע החלוקה.
